# ShadowFleet 前端迁移开发计划

> **目标**：将 ShadowFleet UI 从 Streamlit 迁移到 FastAPI + Vue 3
> **范围**：10 个 UI 页面 + 后端 API 层 + 认证系统 + 实时推送
> **代码复用率**：~80%（业务逻辑层 services/ + database/ 完全复用）
> **创建日期**：2026-04-29

---

## 一、迁移范围概览

### 1.1 代码量统计

| 分类 | 行数 | 复用性 | 说明 |
|------|------|--------|------|
| UI 页面 (ui/pages/) | 2,562 | ❌ 需重写 | Streamlit 页面 |
| UI 支撑代码 (ui/) | ~400 | ⚠️ 50% 复用 | 表单解析、格式化等工具函数 |
| 业务逻辑 (services/) | 4,700 | ✅ 100% 复用 | 纯 Python，无 UI 依赖 |
| 数据访问 (database/) | 4,700 | ✅ 100% 复用 | SQLite + PostgreSQL 操作 |
| **合计** | **~12,000** | **~80% 可复用** | |

### 1.2 技术选型

| 层级 | 当前方案 | 迁移目标 | 备选方案 |
|------|----------|----------|----------|
| 后端框架 | Streamlit 内置 | **FastAPI** | — |
| 前端框架 | Streamlit 原生 | **Vue 3 + TypeScript** | — |
| 状态管理 | st.session_state | **Pinia** | — |
| 表单验证 | Streamlit 原生 | **VeeValidate + Zod** | — |
| 数据请求 | Streamlit 直接调用 service | **Axios + Vue Query** | — |
| 实时推送 | Timer 线程 + st.rerun() | **Server-Sent Events (SSE) + WebSocket** | — |
| 路由 | Streamlit 内置 | **Vue Router 4** | — |
| 样式 | Streamlit 主题 | **Naive UI** | — |
| 组件库 | — | **@vueuse/core**（组合式工具） | — |
| 认证 | config.yaml 单一密码 | **JWT + Redis Session + RBAC** | — |
| 部署 | Streamlit 单进程 | **Docker Compose** (FastAPI + Vue build) | — |
