# ShadowFleet 部署文档

## 环境要求

| 依赖 | 版本 | 说明 |
|------|------|------|
| Python | >= 3.10 | 后端运行时 |
| Node.js | >= 18 | 前端构建 |
| PostgreSQL | >= 14 | Xboard 远程数据库 |
| SQLite | 内置 | 本地状态存储（自动创建） |
| Redis | 可选 | 未来扩展用，当前无需 |

```
ShadowFleet/
├── api/                  # FastAPI 后端
│   ├── main.py           # 应用入口

│   │   └── xboard.py    # Xboard 分组
│   └── auth/             # JWT 认证
├── services/            # 业务逻辑层
├── database/            # 数据访问层
├── frontend/            # Vue 3 SPA
│   ├── src/

│   │   ├── api/         # Axios 客户端
│   │   └── stores/      # Pinia 状态管理

```

## Docker Compose 部署

### `docker-compose.yml`

```yaml
version: '3.9'

services:
  # ── FastAPI 后端 ────────────────────────────────────────────────────────────
  backend:
    build:
      context: .
      dockerfile: Dockerfile.backend
    container_name: shadowfleet-backend
    restart: unless-stopped
    ports:
      - "8000:8000"
    volumes:
      - ./config.yaml:/app/config.yaml:ro
      - ./logs:/app/logs
      - ./shadowfleet.db:/app/shadowfleet.db
    environment:
      - PYTHONUNBUFFERED=1
    healthcheck:
      test: ["CMD", "curl", "-f", "http://localhost:8000/health"]
      interval: 30s
      timeout: 10s
      retries: 3
    depends_on:
      - postgres

  # ── Vue 3 前端 ─────────────────────────────────────────────────────────────
  frontend:
    build:
      context: ./frontend
      dockerfile: ../Dockerfile.frontend
    container_name: shadowfleet-frontend
    restart: unless-stopped
    ports:
      - "3000:80"
    volumes:
      - ./frontend/dist:/usr/share/nginx/html:ro
    depends_on:
      - backend

  # ── PostgreSQL（仅本地开发用，生产使用外部 Xboard DB）───────────────────────
  postgres:
    image: postgres:16-alpine
    container_name: shadowfleet-postgres
    restart: unless-stopped
    environment:
      POSTGRES_USER: shadowfleet
      POSTGRES_PASSWORD: <密码>
      POSTGRES_DB: shadowfleet
    volumes:
      - postgres_data:/var/lib/postgresql/data
    ports:
      - "5432:5432"
    healthcheck:
      test: ["CMD-SHELL", "pg_isready -U shadowfleet"]
      interval: 10s
      retries: 5

volumes:
  postgres_data:
```

### `Dockerfile.backend`

```dockerfile
FROM python:3.12-slim

WORKDIR /app

RUN apt-get update && apt-get install -y --no-install-recommends \
    curl \
    && rm -rf /var/lib/apt/lists/*

COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

COPY . .

RUN useradd --create-home --shell /bin/bash shadowfleet && \
    chown -R shadowfleet:shadowfleet /app

USER shadowfleet

EXPOSE 8000

CMD ["uvicorn", "api.main:app", "--host", "0.0.0.0", "--port", "8000"]
```

### `Dockerfile.frontend`

```dockerfile
# 构建阶段
FROM node:20-alpine AS builder
WORKDIR /app
COPY package*.json ./
RUN npm ci
COPY . .
RUN npm run build

# Nginx 服务阶段
FROM nginx:1.25-alpine
COPY --from=builder /app/dist /usr/share/nginx/html
COPY nginx.conf /etc/nginx/conf.d/default.conf
EXPOSE 80
CMD ["nginx", "-g", "daemon off;"]
```

### `frontend/nginx.conf`

```nginx
server {
    listen 80;
    server_name _;
    root /usr/share/nginx/html;
    index index.html;

    # SPA fallback
    location / {
        try_files $uri $uri/ /index.html;
    }

    # API 反向代理
    location /api/ {
        proxy_pass http://backend:8000/api/;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        # SSE 支持
        proxy_set_header Connection '';
        proxy_buffering off;
        proxy_cache off;
    }
}
```

## 本地开发启动

```bash
# 1. 安装后端依赖
pip install -r requirements.txt

# 2. 安装前端依赖
cd frontend && npm install && cd ..

# 3. 启动后端（开发模式热重载）
uvicorn api.main:app --reload --port 8000

# 4. 启动前端（另一个终端）
cd frontend && npm run dev
```

## 启动 daemon worker

```bash
# 独立进程，执行任务队列中的 provisioning / healing 任务
python -m daemon
```

## 健康检查

```bash
curl http://localhost:8000/health
```

## 升级步骤

1. 拉取最新代码
2. 重新构建前端：`cd frontend && npm run build`
3. 重启后端容器：`docker compose restart backend`
4. 如有数据库迁移，运行迁移脚本
5. 确认所有服务健康
