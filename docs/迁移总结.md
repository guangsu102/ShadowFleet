## 二、技术架构

### 2.1 分层架构

```
┌─────────────────────────────────────────────────────┐
│                   Vue 3 SPA (Naive UI)               │
│         frontend/src/views/ + api/client.ts          │
└──────────────────────┬──────────────────────────────┘
                       │ HTTP + SSE
┌──────────────────────▼──────────────────────────────┐
│              FastAPI (api/main.py)                   │
│  auth/  dashboard/  nodes/  tasks/  assets/         │
│  probes/  monitor/  events/  xboard/  config_api/   │
└──────────────────────┬──────────────────────────────┘
                       │
    ┌──────────────────┼──────────────────┐
    │                  │                  │
    ▼                  ▼                  ▼
 services/         database/        infrastructure/
  (~100%)          (~100%)           (~100%)
```

### 2.2 认证流程

- **JWT Access Token**：15 分钟有效期，存 Pinia store
- **Refresh Token**：7 天有效期，存 localStorage
- **401 自动刷新**：Axios interceptor 拦截，刷新后重试原请求

### 2.3 实时推送架构（SSE）

```
Browser (EventSource) ──→ /api/v1/events/stream
                              │
                              ▼
                    FastAPI StreamingResponse
                    (poll-based, 0.5s interval)
                              │
                              ▼
                    SQLite sse_events 表
                    (daemon 写入，FastAPI 轮询)
                              ▲
                              │
                     Daemon Worker (独立进程)
```

事件类型：
- `task:created` — 新任务创建
- `task:status_changed` — 任务状态变更
- `node:status_changed` — 节点状态变更
- `snapshot:updated` — 快照全量更新

### 2.4 性能优化

| 优化项 | 实现 |
|--------|------|
| Vendor Code Splitting | Vite `manualChunks`：vendor-vue / vendor-naive / vendor-axios |
| 路由懒加载 | 所有 view 使用 `() => import(...)` |
| 大表格虚拟滚动 | NDataTable `virtual-scroll`，节点 >100 行时启用 |
| SSE 自动重连 | `useSSE` composable，断线自动重连 |

## 四、已知限制与后续事项

1. **SSE 生产级替代**：当前 SQLite 轮询方案适合中小规模。如需支持大规模并发，建议引入 Redis Pub/Sub。
2. **前端 API 缓存**：当前无 Vue Query，使用 Axios 直接请求。可按需引入 Vue Query 增强缓存策略。
3. **WebSocket**：当前使用 SSE；如需双向通信，可平滑迁移到 WebSocket。
